Ações restritas, página de consulta pública

O GitHub Pages não oferece acesso privado nativo. Esta tela é publicamente acessível; recursos do repositório principal privado não são copiados para cá antes de aprovação. Aprovações e exclusões são aceitas pelo sistema automatizado apenas quando a solicitação é criada pela conta administradora. Não publique imagens sigilosas nem pedidos privados aqui.

O que fazer: clique na imagem, escolha Aprovar, Desaprovar ou Ajustar, confira a solicitação e envie no GitHub. A criação da Issue é a confirmação da decisão. Para ajustar uma imagem comigo, compartilhe o link da Issue nesta conversa.
